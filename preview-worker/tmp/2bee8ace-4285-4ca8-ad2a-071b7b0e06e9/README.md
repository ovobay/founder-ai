# SaaSify - Marketing Site

This is a modern marketing landing page for SaaSify, a SaaS product that helps teams automate workflows and boost productivity.

## Features

- Hero section with clear value proposition and call to action
- Feature grid highlighting key product benefits
- Pricing section with three plans: Starter, Pro, and Enterprise
- Call to action section encouraging signups
- Responsive design with Tailwind CSS
- SEO-friendly metadata and structure

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/saasify-marketing-site.git
   cd saasify-marketing-site
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Technologies Used

- Next.js 13 with App Router
- React 18
- TypeScript
- Tailwind CSS
