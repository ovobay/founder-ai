# CloudFlow SaaS Landing Page

This is a simple, modern landing page for CloudFlow, a workflow automation SaaS product built with Next.js 13 (App Router), TypeScript, and Tailwind CSS.

## Features

- Hero section with clear value proposition and call to action
- Feature grid showcasing key product features with icons
- Pricing section with three plans and feature lists
- Call to action section encouraging signups
- Responsive and accessible design
- SEO-friendly metadata and structure

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/yourusername/cloudflow-saas-landing.git
cd cloudflow-saas-landing
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Technologies Used

- Next.js 13 with App Router
- React 18
- TypeScript
- Tailwind CSS
